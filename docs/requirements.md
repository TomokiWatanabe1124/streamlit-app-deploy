# 東証 夕方チェックアプリ 要件メモ

## 1. 背景・目的

- 平日の日中は仕事のため、リアルタイムで相場を見られない
- 帰宅後に当日の東証の動きをまとめて確認したい
- 目的は次の2つ
  - **売買タイミングの検討**：気になる銘柄に動きがあったかを確認する
  - **相場全体の雰囲気の把握**：指数や全体ランキングから、今日の地合いをつかむ

## 2. 利用シーン

| 項目 | 内容 |
|---|---|
| 利用時間 | 平日の帰宅後（大引け 15:30 以降） |
| 端末 | PC（ブラウザ） |
| 所要時間 | 約20分 |
| 通知 | 不要（自分でアプリを開く） |

## 3. 機能要件

### F1. 相場サマリー（全体の雰囲気）
- 日経平均・TOPIX の終値と前日比
- 参考指標：ドル円など（任意）

### F2. ウォッチリスト（10〜30銘柄）
- 銘柄ごとに、終値・前日比（円・%）・出来高を表示する
- 銘柄の追加・削除ができる（最初は設定ファイルの編集でよい）
- 銘柄を選ぶと直近のチャートを見られる

### F3. 東証全体ランキング
- 値上がり率と値下がり率の上位を表示する
- ストップ高・ストップ安の銘柄一覧

### F4. 「大きな出来事」の検出・ハイライト
ウォッチ銘柄が次のいずれかに当てはまる場合、目立つように表示する。

| 条件 | 判定方法 |
|---|---|
| 前日比 ±5% 以上 | 終値と前日終値から計算する |
| ストップ高・ストップ安 | 前日終値と東証の値幅制限表から計算した上限・下限に、当日の高値・安値が達したか |
| 業績修正 | 当日の適時開示に「業績予想の修正」などが含まれるか |

### F5. 決算発表スケジュール
- ウォッチ銘柄の次回決算発表予定日を一覧で表示する
- 「今週・来週に発表予定の銘柄」をわかりやすく表示する
- 必要に応じて、東証全体の発表予定（日付ごとの件数・主要銘柄）も表示する

## 4. 非機能要件

- 無料で運用できること（Streamlit Community Cloud）
- PC のブラウザで見やすい画面構成（タブ、または上から順に読める構成）
- 休場日（土日・祝日・年末年始）でもエラーにならず、直近の営業日のデータを表示する
- 取得したデータはキャッシュして、何度開いても速く表示する

## 5. データソース（検証済み）

| 用途 | 採用 | 検証結果・備考 |
|---|---|---|
| 株価・指数 | Yahoo Finance（yfinance） | 非公式。仕様変更で動かなくなることがある。TOPIX・グロース250は指数がないため連動 ETF（1306、2516）で代用 |
| 全体ランキング | Yahoo の quote API を 200 銘柄ずつ呼ぶ | 全約3,700銘柄を数秒で取得できる。日足の一括ダウンロードは約7.5分かかり、レート制限で約3割を取りこぼしたため不採用 |
| 銘柄一覧 | JPX「東証上場銘柄一覧」 | プライム・スタンダード・グロースの内国株式を対象にする（ETF・REIT・PRO Market は除く） |
| ストップ高・安 | 前日終値と東証の制限値幅表から計算 | 値幅の拡大措置などの例外は考慮しない |
| 業績修正 | TDnet の開示一覧の表題から判定 | 「業績予想…修正」「上方修正」「下方修正」などのパターンで判定する |
| 決算予定日 | JPX「決算発表予定日」 | 決算期末の月ごとに公表されるため、先の予定はまだ載っていないことがある。ウォッチ銘柄は Yahoo の予定日で補う |

## 6. 決定事項

- ウォッチ銘柄：2801 キッコーマン、8410 セブン銀行、9009 京成電鉄（今後追加・削除あり → `watchlist.csv` で管理）
- 全体ランキングの対象：東証全銘柄（プライム・スタンダード・グロースの内国株式）
- ランキングの表示件数：上位20件
- 決算スケジュールの範囲：東証全体（ウォッチ銘柄には ⭐ を付ける）
