# 東証 夕方チェック

平日の帰宅後に、当日の東証の相場をまとめて確認するための Streamlit アプリです。
要件は [docs/requirements.md](docs/requirements.md) にあります。

## 画面

| タブ | 内容 |
|---|---|
| 📊 サマリー | ウォッチ銘柄の注目ポイント、指数（日経平均・TOPIX・グロース250・ドル円）、値上がり/値下がり銘柄数、業種別騰落率 |
| ⭐ ウォッチリスト | 終値・前日比・出来高倍率、ストップ高・安、次回決算日、直近の適時開示、ローソク足チャート |
| 🏆 ランキング | 東証全銘柄（プライム・スタンダード・グロース）の値上がり率・値下がり率 上位20、ストップ高・安の一覧 |
| 📰 適時開示 | TDnet の開示一覧（業績修正・配当・決算で絞り込み、キーワード検索） |
| 📅 決算スケジュール | 東証全体の決算発表予定（日別の件数、日付ごとの一覧） |

ウォッチ銘柄が次のいずれかに当てはまると、黄色でハイライトされます。

- 前日比 ±5% 以上
- ストップ高・ストップ安（引け、または一時到達）
- 当日に業績修正の開示がある

## ウォッチ銘柄の追加・削除

`watchlist.csv` を編集します。GitHub の画面でファイルを開き、鉛筆アイコンから編集してコミットすれば、公開中のアプリにも反映されます。

```csv
code,name,memo
2801,キッコーマン,
8410,セブン銀行,
9009,京成電鉄,
```

## 手元で動かす

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

テスト: `pip install pytest && python -m pytest tests`

## 公開する（Streamlit Community Cloud）

1. https://share.streamlit.io に GitHub アカウントでログインする
2. 「Create app」でこのリポジトリ、ブランチ、`app.py` を選んで Deploy する
3. 発行された URL をブックマークする

## データの出所と注意

| データ | 出所 |
|---|---|
| 株価・指数 | Yahoo Finance（yfinance 経由。非公式 API のため仕様変更で動かなくなることがあります） |
| 上場銘柄一覧・決算発表予定日 | 日本取引所グループ（JPX）の公開ファイル |
| 適時開示 | TDnet（適時開示情報閲覧サービス） |

- TOPIX とグロース250は指数そのものを取得できないため、連動 ETF（1306、2516）で代用しています。
- ストップ高・安は、前日終値と東証の通常の制限値幅から計算しています。値幅の拡大措置などの例外は考慮していません。
- JPX の決算発表予定日は決算期末の月ごとに公表されます。まだ載っていない銘柄は、Yahoo の予定日（推定の場合あり）を参考表示します。
- 個人の情報収集用です。投資判断はご自身の責任で行ってください。
