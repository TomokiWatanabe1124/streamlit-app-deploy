# 東証 夕方チェックアプリ 要件メモ

## 1. 背景・目的

- 平日の日中は仕事のため、リアルタイムで相場を見られない
- 帰宅後に当日の東証の動きをまとめて確認したい
- 目的は次の2つ
  - **売買タイミングの検討**：気になる銘柄に動きがあったかを確認する
  - **相場全体の雰囲気の把握**：指数や全体ランキングから、今日の地合いをつかむ

## 2. 利用シーン

| 項目 | 内容 |
|---|---|
| 利用時間 | 平日の帰宅後（大引け 15:30 以降） |
| 端末 | PC（ブラウザ） |
| 所要時間 | 約20分 |
| 通知 | 不要（自分でアプリを開く） |

## 3. 機能要件

### F1. 相場サマリー（全体の雰囲気）
- 日経平均・TOPIX の終値と前日比
- 参考指標：ドル円など（任意）

### F2. ウォッチリスト（10〜30銘柄）
- 銘柄ごとに、終値・前日比（円・%）・出来高を表示する
- 銘柄の追加・削除ができる（最初は設定ファイルの編集でよい）
- 銘柄を選ぶと直近のチャートを見られる

### F3. 東証全体ランキング
- 値上がり率と値下がり率の上位を表示する
- ストップ高・ストップ安の銘柄一覧

### F4. 「大きな出来事」の検出・ハイライト
ウォッチ銘柄が次のいずれかに当てはまる場合、目立つように表示する。

| 条件 | 判定方法 |
|---|---|
| 前日比 ±5% 以上 | 終値と前日終値から計算する |
| ストップ高・ストップ安 | 前日終値と東証の値幅制限表から計算した上限・下限に、当日の高値・安値が達したか |
| 業績修正 | 当日の適時開示に「業績予想の修正」などが含まれるか |

### F5. 決算発表スケジュール
- ウォッチ銘柄の次回決算発表予定日を一覧で表示する
- 「今週・来週に発表予定の銘柄」をわかりやすく表示する
- 必要に応じて、東証全体の発表予定（日付ごとの件数・主要銘柄）も表示する

## 4. 非機能要件

- 無料で運用できること（Streamlit Community Cloud）
- PC のブラウザで見やすい画面構成（タブ、または上から順に読める構成）
- 休場日（土日・祝日・年末年始）でもエラーにならず、直近の営業日のデータを表示する
- 取得したデータはキャッシュして、何度開いても速く表示する

## 5. データソース候補（要検証）

| 用途 | 候補 | 懸念点 |
|---|---|---|
| 株価・指数 | yfinance | 非公式。仕様変更で動かなくなることがある |
| 全体ランキング | yfinance で全銘柄を一括取得 / ランキング掲載サイト | 全約3,900銘柄の取得は重い。対象を絞るか取得方法を検討する |
| ストップ高・安 | 株価データと東証の値幅制限表から計算 | 値幅制限が拡大された銘柄などの例外がある |
| 業績修正 | TDnet（適時開示） | 取得方法と利用条件を確認する |
| 決算予定日 | JPX が公開している決算発表予定日、yfinance の calendar | 更新頻度と網羅性を確認する |

## 6. 優先順位（段階的に作る）

1. **v0.1**：F1 相場サマリー、F2 ウォッチリスト、F4 のうち「±5%」判定
2. **v0.2**：F5 決算発表スケジュール
3. **v0.3**：F4 のストップ高・安、業績修正の判定
4. **v0.4**：F3 東証全体ランキング
